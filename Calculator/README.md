🧮 Android Calculator (Kotlin)

A simple calculator app built with **Kotlin** for Android. It supports basic arithmetic operations and has a clean, user-friendly UI.

🚀 Features

- Basic operations: `+`, `-`, `×`, `÷`
- Sign toggle `(+/-)`
- Percentage calculation `%`
- Reset button `AC`
- Decimal and comma support
- Built with `TableLayout` and `ConstraintLayout`

🛠 Tech Stack

- Kotlin
- Android SDK
- XML Layouts

🧠 How It Works

- `btnSayiTik()` handles number inputs and sign changes  
- `btnOptik()` stores selected operator  
- `btnEsittirTik()` computes and shows the result  
- `btnYuzdeTik()` divides the number by 100  
- `btnAC()` resets everything
